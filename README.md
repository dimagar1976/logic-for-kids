**Курс формальной логики для младших школьников** — 13 интерактивных уроков, где абстрактные законы мышления становятся понятными через детективные миссии, персонажей и жизненные примеры.

## 🎭 Персонажи курса

- 🧙 **Профессор Винтик** — мудрый наставник, объясняет правила логики
- 🤖 **Робот Ворчун** — милый «не логик», через ошибки которого ребёнок учится находить противоречия
- 👧 **Мила** и другие юные сыщики — решают задачи вместе с ребёнком

## 🔬 Методология

Курс создан на стыке **формальной логики**, **возрастной психологии** и **педагогического дизайна**.

### 1. Опора на классический источник
В основу положен учебник **«Логика» С. Н. Виноградова** (для средней школы). Строгие логические структуры сохранены, идеологический контекст полностью удалён.

### 2. Учёт когнитивного развития (по Ж. Пиаже)
Дети 7–9 лет находятся на **стадии конкретных операций**. Поэтому:
- Объём понятия объясняется через вложенные «коробки»
- Пересечение понятий визуализируется диаграммами Эйлера–Венна
- Силлогизм подаётся как работа детектива, ищущего «связующее звено»

### 3. Принцип скаффолдинга
Каждая миссия построена по единому алгоритму:
1. **Сюжет** — игровая ситуация с проблемой
2. **Правило** — краткая логическая закономерность
3. **Визуализация** — схема, поддерживающая правило
4. **Вопрос** — проверка на аналогичном примере
5. **Обратная связь** — разбор ошибки, а не просто «неверно»

### 4. Формирование научного скептицизма
Курс учит распознавать:
- «поспешное обобщение»
- «подмену тезиса»
- «порочный круг»
- «утверждение следствия»

Ребёнок учится говорить: **«Этого недостаточно, чтобы сделать такой вывод»**.

## 💻 Технологии

- **HTML5** — семантическая вёрстка, ARIA-атрибуты для доступности
- **CSS3** — Flexbox, Grid, CSS-переменные, SVG для диаграмм
- **Vanilla JavaScript (ES6+)** — алгоритм Фишера–Йетса для перемешивания ответов, защита от двойных кликов через токены, адаптивная система повторения ошибок через `localStorage`

Проект **не требует сборки, Node.js или сервера** — работает прямо из браузера.
